CONTEXT　［地球という船］　約25秒

人類は、
船を乗り換えられるのか。

バックミンスター・フラー『宇宙船地球号 操縦マニュアル』地球『インターステラー』

CONTEXT STORY

意味の上での近さから結ばれた区間。

バックミンスター・フラーは、地球を、限られた資源で宇宙を航行する一隻の船にたとえ、人類はその操縦法を学ばねばならないと説いた。

『インターステラー』の人類は、その船がもう持たないと知り、乗り換える先を探しに星の海へ出る。

操縦法を学べなかった未来と、学ぼうとする現在。フラーの言葉は、映画を観たあとに読むと、半世紀前からの警告として響く。
