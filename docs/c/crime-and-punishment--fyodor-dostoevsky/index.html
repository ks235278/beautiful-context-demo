CONTEXT STORY

罪は、法よりも先に心を裁く。

ドストエフスキーの代表作の一つ『罪と罰』は、1866年に雑誌『ロシア報知』に連載された。主人公ラスコーリニコフは、非凡な人間には法を踏み越える権利があるという自分の理屈で老婆を殺す。

しかし罪の意識は、予審判事ポルフィーリーの追及より先に、彼を追いつめていく。ドストエフスキーは、熱に浮かされたような心の揺れを描いた。ポルフィーリーとの三度の論戦は、推理小説の対決のようにも読める。
