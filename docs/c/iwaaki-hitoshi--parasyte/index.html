CONTEXT STORY

作者の名を知らしめた長編。

『寄生獣』は1988年から1995年まで連載された。人間を捕食する寄生生物と、それに右手だけを奪われた高校生の共生を通して、人間という種そのものを外側から見つめる物語である。

淡々とした線と、容赦のない出来事。その落差が生む緊張感は、のちの『ヒストリエ』にも受け継がれている。

この先のつながり

  1. 漫画・1988年 岩明均『寄生獣』人間に寄生する生物が現れた世界で、右手に寄生された高校生・泉新一と「ミギー」の共生を描いた漫画。
  2. ［体に宿るもう一つの命］　似ている 悪魔の心臓と、右手の寄生生物。›› 漫画・2018年 藤本タツキ『チェンソーマン』悪魔のポチタと一体になり、チェンソーの悪魔の力を得た少年デンジの物語。2018年に週刊少年ジャンプで連載が始まった。
  3. ［悪魔を狩る少年］　作者と作品 借金を背負った少年に、チェンソーの心臓が宿る。›› 人物 藤本タツキ『チェンソーマン』『ルックバック』『ファイアパンチ』の漫画家。
  4. ［描く人を描く］　作者と作品 漫画家が、漫画を描く人を描いた。›› 漫画・2021年 藤本タツキ『ルックバック』漫画を描くことに打ち込む二人の少女を描いた読み切り。2021年に少年ジャンプ＋で公開され、2024年にアニメーション映画になった。
  5. ［描く手］　似ている 描くことを奪われても、描いた日々は消えない。›› 映画・2016年 『この世界の片隅に』戦時中の広島と呉を舞台に、絵を描くことが好きな主人公すずの暮らしを描いたアニメーション映画。原作はこうの史代の漫画。
  6. ［映画のはじまりの歌］　事実 戦時下の日常は、この歌から始まる。›› 音楽・1968年 「悲しくてやりきれない」1968年に発表されたザ・フォーク・クルセダーズの歌。多くの歌い手にうたい継がれてきた。
  7. ［うたい直された歌］　事実 1968年の歌を、静かな声がうたい直した。›› 音楽 コトリンゴピアノと歌のシンガーソングライター。アニメーション映画『この世界の片隅に』の音楽を手がけ、「悲しくてやりきれない」を歌った。
  8. この世界の片隅に から分岐 ［嫁いだ先の町］　事実 すずは広島から、軍港の町へ嫁いだ。›› 場所 広島県呉市瀬戸内海に面した港町。明治期に海軍の鎮守府が置かれ、戦艦大和が建造された海軍工廠の町として知られる。
  9. ［呉の一皿］　事実 港町の居酒屋の味が、缶ひとつで旅をする。›› 料理 鳥皮みそ煮広島県呉市の名物料理。鶏の皮をこんにゃくと一緒に味噌で煮込んだ一皿で、呉の居酒屋では「みそだき」とも呼ばれる。
  10. この世界の片隅に から分岐 ［1945年の空］　似ている 同じ年の戦争を、前線と台所から見た。›› 人物・1918年 W・ユージン・スミスアメリカの写真家。「ライフ」誌のフォトエッセイで知られ、1970年代には熊本県水俣に移り住んで水俣病を撮った。
  11. ［水俣を撮った人］　事実 写真が、世界に水俣を伝えた。›› 映画・2020年 『MINAMATA』水俣病を世界に伝えた写真家W・ユージン・スミスと、アイリーン・美緒子・スミスの水俣での日々を描いた映画。音楽は坂本龍一。
  12. ［写真家を演じる］　事実 海賊を演じた俳優が、水俣の写真家になった。›› 人物・1963年 ジョニー・デップアメリカの俳優。ティム・バートンやテリー・ギリアムの作品に数多く出演し、『MINAMATA』では主演とともに製作にも加わった。
