CONTEXT　［ロンドンの入れ違い］

同じ年生まれの二人は、
ロンドンで入れ違った。

南方熊楠（1867年生まれ）ロンドン夏目漱石（1867年生まれ）

CONTEXT STORY

ハブはロンドン。同じ年に生まれた二人の、入れ違い。

南方熊楠と夏目漱石は、どちらも1867年に生まれた。熊楠は1892年から1900年までロンドンに住み、大英博物館に通って学んだ。

熊楠がロンドンを離れたのは1900年9月。その翌月の10月末、入れ替わるように漱石が留学生としてロンドンに着く。

漱石は下宿先を転々とし、神経衰弱に陥った。熊楠は博物館で蔵書を筆写し、そのノート『ロンドン抜書』は52冊に及んだ。同じ都市で対照的な留学生活を送った二人は、そこでは顔を合わせないまま入れ違いになった。二人は1884年、ともに大学予備門に入学した同窓でもあった。
