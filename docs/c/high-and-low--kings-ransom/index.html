CONTEXT　［小説から映画へ］　約50秒

身代金の電話は、
横浜の高台で鳴った。

エド・マクベイン『King’s Ransom』（1959）黒澤明『天国と地獄』（1963）

CONTEXT STORY

黒澤は、アメリカの警察小説を高度経済成長期の日本へ移した。

『天国と地獄』は、まったくのオリジナル脚本ではない。原作は、エド・マクベインの〈87分署シリーズ〉の一作『King’s Ransom』（1959）である。

取り違えられた子ども

靴会社の重役のもとに「息子を誘拐した」という電話がかかる。ところが連れ去られたのは、彼の息子ではなく、運転手の息子だった。他人の子のために全財産を差し出すのか。物語の芯になるこの問いは、小説から映画へそのまま受け継がれている。

移し替えられたもの

黒澤は舞台を横浜に移し、誘拐サスペンスを、階級の格差と高度経済成長期の日本社会を描く映画へと大きく広げた。高台の邸宅と、それを見上げる下界。その高低差が、日本語の題名『天国と地獄』そのものになっている。

そして約60年後、スパイク・リーはこの同じ小説を企画の出発点に、物語をふたたびニューヨークへ戻すことになる。
