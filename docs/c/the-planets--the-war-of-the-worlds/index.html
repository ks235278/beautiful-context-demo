CONTEXT　［火星、戦争をもたらす者］

組曲の最初の星は、
戦争の神だった。

ホルスト『惑星』第1曲「火星、戦争をもたらす者」火星H・G・ウェルズ『宇宙戦争』

CONTEXT STORY

意味の上での近さから結ばれた区間。どちらも、火星を「戦争」として描いた英国の作品である。

ホルストの組曲『惑星』は、第1曲「火星、戦争をもたらす者」の、執拗に刻まれる五拍子のリズムで始まる。作曲は1914年から1917年、第一次世界大戦のさなかである。ただし最初に書かれた「火星」は、開戦前に書き上げられていた。

その十数年前の1898年、H・G・ウェルズは『宇宙戦争』で、火星人が当時最大の植民地帝国だった英国に襲来し、軍隊の抵抗を押し切ってロンドンを含む南イングランドを蹂躙するさまを描いた。

惑星を占星術の性格で描いた組曲と、惑星からの侵略を描いた小説。宇宙を見上げながら、英国は二度、火星に戦争の顔を見ていたとも言える。「木星」の旋律は、のちに愛国歌「我は汝に誓う、我が祖国よ」になり、前田先生はこの曲を、英国人の気概を知る手がかりとして紹介している。
