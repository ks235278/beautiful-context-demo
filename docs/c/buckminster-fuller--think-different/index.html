CONTEXT　［クレイジーな人たち］

世界を変えられると
本気で信じる一人。

バックミンスター・フラー広告に登場アップル「Think Different」

CONTEXT STORY

広告に登場した一人。

1997年のアップルの「Think Different」のテレビ広告（60秒版）には、アインシュタイン、キング牧師、ガンディー、ピカソらとともに、バックミンスター・フラーの姿が映る。

フラーの肩書きは、思想家、建築家、発明家、詩人など、ひとつに収まらない。広告は、自分が世界を変えられると本気で信じる人たちこそが、実際に世界を変えている、と語りかける。フラーは、その「クレイジーな人たち」の一人として登場する。
