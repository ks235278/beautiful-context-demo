CONTEXT STORY

広告に登場した一人。

1997年のアップルの「Think Different」のテレビ広告には、アインシュタイン、キング牧師、ガンディー、ピカソらとともに、バックミンスター・フラーの姿が登場する。

建築家とも発明家とも詩人ともつかない、分類できない思想家。自分は世界を変えられると信じる人こそが世界を変える、という広告の言葉に、フラーほどふさわしい人はいなかった。
