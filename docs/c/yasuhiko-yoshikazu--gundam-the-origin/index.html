安彦良和『機動戦士ガンダム THE ORIGIN』

CONTEXT STORY

アニメ版の作り手の一人が、その物語を漫画で描き直した。

安彦良和は、1979年のテレビアニメ『機動戦士ガンダム』でキャラクターデザインと作画監督をつとめた。

2001年から2011年まで雑誌『ガンダムエース』に連載された『機動戦士ガンダム THE ORIGIN』は、安彦自身が描き直したガンダムの物語で、アニメではほとんど描かれなかったシャアとセイラの過去も描かれている。
