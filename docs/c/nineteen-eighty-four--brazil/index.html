CONTEXT STORY

『未来世紀ブラジル』の仮題『1984½』は、迫りくる1984年と、フェリーニへの敬意から生まれた。

テリー・ギリアムは『未来世紀ブラジル』の制作中、『1984½』という題を考えていた。本人の説明によれば、敬愛するフェリーニと、迫りくる1984年を重ねた題である。フェリーニの『8½』にならった題で、英語版Wikipediaは、オーウェルの『1984年』への目配せでもあったと紹介している。

書類と配管と手続きにがんじがらめになった社会で、夢に逃げ込むしかない役人。ギリアムは自作を「1984年版『1984年』」と呼び、小説の再現ではなく、今日の視点から未来を描いたと説明している。一方、2003年のインタビューでは、オーウェルの小説を読んだのは映画のあとだったとも話している。

1985年に公開されたこの映画は、「1984年」が現実に過ぎ去ったあとに、なお終わらないディストピアを描いていると読める。
