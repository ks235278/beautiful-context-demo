CONTEXT STORY

画面の向こうの国は、東京の街角にもある。

『アイリス』は、韓国の特殊工作員を主人公にしたアクション・ドラマ。日本でも放送され、秋田でのロケも話題になった。

赤坂には韓国料理の店が集まる一角があり、「ヌルンジ」もそのひとつ。店名は韓国語で、釜の底にできるおこげのこと。韓国では、おこげに湯を注いだ「スンニュン」を食後に飲む習慣がある。

ドラマで知った国へのいちばん近い入口は、案外、一皿の料理なのかもしれない。

  1. 店 ヌルンジ（赤坂）東京・赤坂の韓国料理店。店名の「ヌルンジ」は韓国語で、釜の底にできるおこげのこと。
