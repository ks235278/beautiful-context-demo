T・S・エリオットの詩集原作ミュージカル『キャッツ』

CONTEXT STORY

難解な詩人が、子どもたちのために猫の詩を書いた。

ミュージカル『キャッツ』の原作は、T・S・エリオットの詩集『Old Possum’s Book of Practical Cats』（1939）。名付け親の子どもたちのために書いた、ユーモラスな猫の詩の本だ。

アンドリュー・ロイド・ウェバーはその詩に曲をつけ、1981年にロンドンで舞台にした。代表曲「メモリー」の歌詞にも、エリオットの詩の言葉が使われている。

『荒地』の詩人と、世界でもっとも長く上演されたミュージカルの一つ。意外な二つは、同じ一人の手でつながっている。
