CONTEXT STORY

意味の上での近さから結ばれた区間。異国の都で、留学生が自分の学びと向き合いながら書いた。

夏目漱石は1900年から約2年間、文部省の留学生としてロンドンに暮らした。下宿にこもって英文学と格闘し、神経をすり減らした日々は、漱石自身が『文学論』の序に書き残している。妻への手紙にも、ロンドンでの孤独を訴える言葉が見える。

その十数年後、今度は中国から周恩来が東京にやって来た。受験勉強と挫折、祖国への思いを綴った日記は、のちに『十九歳の東京日記』として読まれている。

日本から西洋へ向かった留学生と、中国から日本へ向かった留学生。向きは違っても、異国の都で自分の学びと向き合った記録として、二つは並べて読むことができる。
