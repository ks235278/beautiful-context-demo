CONTEXT STORY

映画の脚本家の一人は、小説家であり劇作家でもある。

ペーター・ハントケはオーストリアの作家で、『ベルリン・天使の詩』ではヴィム・ヴェンダースらとともに脚本に名を連ねている。デビュー小説『Die Hornissen』（1966）や、俳優が観客を罵る劇『観客罵倒』で、早くから文壇に名を刻んだ。

2019年、ハントケはノーベル文学賞を受けた。授賞理由は、「言語的な独創性によって、人間の経験の周縁と特殊性を探究した、影響力のある作品」である。

授賞には批判もあった。ハントケの政治的な発言をめぐり、ボスニアやコソボで反発の声が上がり、アルバニアやトルコを含む複数の国が授賞式のボイコットや欠席を表明した。スウェーデン・アカデミー側は、授賞を擁護した。
