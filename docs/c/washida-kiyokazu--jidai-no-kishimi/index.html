CONTEXT STORY

前田先生が note に書き写した一節から。

書き写されたのは鷲田清一の文章で、note の日付は2017年12月30日。出典には『＜わたし＞と国家のあいだ』とある。『時代のきしみ』の副題と同じ題だ。

文章は、こう始まる。「ひとは時代を拒否し、時代から遁走しようとすればするだけ、より緻密に時代に絡みとられてゆく。」法律や制度、習俗や縁といった生の背景が、もはや背景ではすまなくなるからだ、と鷲田は書く。

鷲田はさらに、わたしたちの存在を編んでいる意味の糸が、思考や欲望のかたちを左右するだけでなく、システムの貫通や包囲をかわそうとする「抵抗のスタイル」までも規定している、と述べる。結びの一文はこうだ。「その意味で、時代を拒否するとは、ほとんどじぶんの存在を脱臼させるにひとしい。」
