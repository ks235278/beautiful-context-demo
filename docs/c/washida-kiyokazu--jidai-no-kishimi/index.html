CONTEXT STORY

前田先生が書き写した一節から。

鷲田清一は、ひとは時代を拒否し、時代から遁走しようとするほど、より緻密に時代に絡めとられてゆく、と書く。法律や制度、習俗や縁といった生の背景が、もはや背景ではすまなくなるからだ。

わたしたちの存在を編んでいる意味の糸は、思考や欲望のかたちだけでなく、それに抵抗するスタイルまでも決めてしまう。前田先生は2017年の暮れ、この一節を note に書き写している。
