CONTEXT　［支配する側の闇］

植民地を統べる者の
心の奥。

ジョセフ・コンラッド『闇の奥』植民地支配ジョージ・オーウェル『象を撃つ』

CONTEXT STORY

意味の上での近さから結ばれた区間。

コンラッドの『闇の奥』は、1899年に連載された。船乗りマーロウが、象牙取引の奥地コンゴで消息を絶ったクルツを探しに向かう。文明の使者であるはずのクルツが壊れていくさまを、欧州の側から描いた。

オーウェルの『象を撃つ』（1936）は、ビルマで、権威ある白人警官であることを群衆に示すために象を撃つ「私」を描いた。笑われまいとして引き金を引く「私」は、白人が暴君になるとき壊されるのは自分自身の自由だ、と書き留める。

どちらも、支配される側ではなく、支配する側の人間の内面に目を向けている。前田先生は2018年8月の二つの note で、『象を撃つ』に権力の側にある人間の内面的な敗北を、『闇の奥』（Heart of Darkness）に「（自称）文明人の心の闇」を読んでいる。帝国の時代を内側から見つめた英語の二つの作品は、並べて読むことで互いの輪郭をはっきりさせる。
