CONTEXT STORY

若い女性の実体験の旅が、のちに、まったく別の物語として映画になった。

森村桂は1964年、1ドルが360円で海外渡航にも制限があった時代に、亡き父が語った「天国にいちばん近い島」を探して、ひとりでニューカレドニアへ旅立った。船会社の社長に手紙で頼み、運搬船にただで乗せてもらっての旅で、その記録が1966年に刊行された『天国にいちばん近い島』である。前田先生の note によれば、旅先で盲腸になった彼女を助けたのは、日本人の血を引く無国籍の男性ムッシュ・ワタナベだった。

大林宣彦は1984年、原田知世の主演で、同じ題名の映画を撮った。主人公は父を亡くした高校生の桂木万里で、筋は原作とまったく異なる。映画には、戦争で夫を亡くした女性（石川貞）が、夫の亡くなった海を主人公と訪れる場面がある。前田先生の note によれば、これは原作にない挿話で、未亡人は近海で沈んだ日本の潜水艦の兵士の慰霊碑を供養に訪れる。先生は、大林監督が戦争や政治の重い影をあえて前面に出さず、日本との暗い過去とのつながりをさりげなく挿入した、と読んでいる。
