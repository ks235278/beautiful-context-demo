**公開URL** → https://ks235278.github.io/beautiful-context-demo/

|---|---|---|

## 読者の画面

```
起動画面            BEAUTIFUL CONTEXT。回路の模様が画面いっぱい
   ↓ スクロール      表題が上へ流れて消え、路線図の見出しが流れ始める
路線図              UniverseIt! と「言葉で辿る」検索。見出しはすべて押せる
   ↓ UNIverseIt!    続きが開き、そのまま送り込まれる
ストリーム          表のカードが縦に並ぶ（新しい順）
   ↓ カードを押す    その場で裏返り、裏面（コンテクスト）になる
```

- **表（カード）** … A の画像に B の画像を重ね、手書き風の線でつなぐ。線は 4 形 × 6 色
- **裏（コンテクスト）** … A の画像を 20% に透かし、その上を文章が流れる。最後に生成AI の出典 URL
- **同じルーツ** … 同じ作品を共有するコンテクストへ、カードの直下から文字だけでつなぐ
- **広告枠** … カード 2 件ごとに一枠（間隔は運営者メニューで変更）
- **共感・コメント・つなぐ・共有** … カードの下の列から
- **駅（作品）** … 作品ごとに、その作品から延びる区間を一覧

戻る操作は、携帯では右へ払う、パソコンではブラウザの戻るか Esc。
重ねて開いた画面は URL に残る（`#/c/…` 裏面、`#/w/…` 作品）ので、
そのまま共有できます。

## 運営者メニュー

| 項目 | できること |
|---|---|
| コンテクスト | 公開 / 非公開 / 一時非表示の切り替え、理由のメモ、表示・編集・つなぐ・削除、絞り込み |
| コメント | 表示 / 非表示、削除 |
| 広告枠 | 画像・見出し・リンク先・表示の有無、挟む間隔、枠の追加と削除 |
| 書き手 | 書き手ごとにまとめて一時非表示 |
| カスタマイズ | サービス名・ひとこと・地（チャコール / ホワイト）・アクセント色。プレビュー付き |
| データ | 書き出し（.json）・読み込み・見本に戻す |
| 機能一覧 | 構成図の番号順の対応表 |

非公開は書き手の下書き、一時非表示は運営の判断で止めている状態です。
どちらもストリーム・路線図・検索から消え、データは残ります。

## 保存先について

サーバーはありません。データはブラウザの `localStorage` に入ります。

- 作ったものは**その端末のそのブラウザにだけ**残ります
- パソコンで準備した内容を携帯で見せるときは、運営者メニューの
  **データ → 書き出す** で保存したファイルを、携帯で **読み込む**

以前の版で作ったコンテクストは、初めて開いたときに自動で引き継がれます。

## 地色について

模様が乗った面と無地の面は、同じ色でも濃さが違って見えます。実機の
スクリーンショットから画素を測り、見えている色と地色が一致する値を
解いて `--ground: #141c25` としました。canvas で SVG を描き直して
測った値は Safari の実描画と合わなかったため使っていません。

ための引用として使っています。著作権は各権利者に帰属します。
一般公開の前には、権利処理済みの画像に差し替えてください。

見本の本文のうち、HIGHEST 2 LOWEST と グレン・グールド の二件は前田先生の
資料に基づきます。ほかの三件は見本として書いたもので、確かめられる事実だけを
書き、言い伝えは「伝えられる」と書いています。
