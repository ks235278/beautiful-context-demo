## 50タイトルのつながり

前田先生の 50 タイトルを、先生の分類（**事実 ／ ハブ ／ 似ている ／ 作者と作品**）で
つないでいます。

- 49 作品・49 区間。先生の資料にある 5 区間はそのまま、残り 44 区間は**生成AIの初稿**
- 14 区間はまとまりをまたぐ（例：コッポラ ⇄ 天国と地獄〔ハブ：黒澤明〕、
  万引き家族 ⇄ 地獄の黙示録〔パルム・ドール〕、この世界の片隅に ⇄ ルックバック〔描く手〕）
- 区間ごとに型・ハブ・四軸（意外性・共感度・コンテンツ性・世界観近似性、各 1〜5）を持ち、
  コンテクストページの読み終わりに表示する
- AGM：初稿のページには「生成AIの初稿・編集者の確認前」と出る。運営者メニューで
  「承認」すると「確認済み」に変わる
- 「ムルンジ」は特定できずつないでいない。「鳥皮みそ煮 ⇄ 呉」は根拠待ちで非公開の下書き
- 作品の絵（`docs/img/works/`）は、映画のポスター（映画.com）、漫画の表紙（集英社・講談社）、
  配信作品のキービジュアル（Apple TV・Prime Video）、人物や土地の写真（Wikimedia Commons の
  自由に使えるもの）。出典は作品ページとアプリの「画像の出典」ページに出る。
  鳥皮みそ煮・ムルンジだけは題名を組んだ札（`docs/img/cards/`）のまま

すでにデモを開いたことのある端末にも、新しい区間は自動で足されます
（端末で書き直した見本と、消した見本はそのまま）。

## 読者の画面

**flow0921-2.pdf と demo-1.html の見た目どおりに組んでいます。**
背景の回路は、先生の構成図に入っている画像（A / WHITE・B / CHARCOAL）そのものを
切り出して使っています。表紙の BEAUTIFUL CONTEXT は構成図と同じ Bebas Neue です。

```
表紙                回路の絵に BEAUTIFUL CONTEXT。数秒で、または触れると次へ
   ↓
UniverseIt!         「# 言葉」を横に並べて折り返す一覧。指で普通にスクロールする
                    下に BEAUTIFUL CONTEXT と、橙「つながりを創る」紺「つながりを辿る」
   ↓ # 言葉
作品ページ A  ⇄  コンテクストページ A―B  ⇄  作品ページ B      … demo-1 の形
                    下の路線図の駅と区間、「コンテクストを見る」、左右の払い、← → キー
   ↓ つながりを辿る（UniverseIt!）   ↓ つながりを創る（ReMixIt!）
UniverseIt! へ戻る                     エディター
```

- 右上の ≡ に、言葉で辿る（検索）・Our Mission・広告枠・画像の出典・規約・運営者メニューと、
  地の切り替え（A / WHITE・B / CHARCOAL）
- 作品ページ：黒地に絵、紙の地に明朝で作品固有の解説だけ
- コンテクストページ：黒地に二枚の絵と ↔、紙の地に路線名・見出し・関係、その下に CONTEXT STORY
- 下の路線図：いま居る駅は輪が大きく、コンテクストページでは「区間を読書中」

**ページの切り替えは、絵が動いてつなぐ**（先生の「スマホらしい切り替えを」）。

- # 言葉に触れる：触れた言葉の位置から作品の絵が開く
- 作品ページ A → コンテクストページ：A の絵が縮んで左に収まり、B の絵が右から入る
- コンテクストページ → 作品ページ B：B の絵が広がって B のページになり、A は去る
- つながりを辿る で戻る：絵が縮んで、UniverseIt! の中へ溶ける

スクロールは普通のスクロールのままで、画面を勝手に動かしたり、文字を流したりはしません。

コンテクストページの読み終わりには、生成AIの出典、同じ作品をルーツに持つ
ほかの区間、広告枠（記事単位）が並ぶ。

戻る操作は、携帯では右へ払う、パソコンではブラウザの戻る・Esc。
開いたページは URL に残る（`#/w/…` 作品、`#/c/…` コンテクスト）ので、そのまま共有できる。

## 運営者メニュー

| 項目 | できること |
|---|---|
| コンテクスト | 公開 / 非公開 / 一時非表示の切り替え、理由のメモ、表示・編集・つなぐ・削除、絞り込み。型・ハブ・四軸の表示、AI初稿の承認 |
| 広告枠 | コンテクストページの読み終わりに出す枠。画像・見出し・リンク先・使う／使わない |
| 書き手 | 書き手ごとにまとめて一時非表示 |
| カスタマイズ | サービス名・ひとこと・地（チャコール / ホワイト）・アクセント色。プレビュー付き |
| データ | 書き出し（.json）・読み込み・見本に戻す・つながり一覧（.csv・Excel 用） |
| 機能一覧 | 構成図の番号順の対応表 |

非公開は書き手の下書き、一時非表示は運営の判断で止めている状態です。
どちらも UniverseIt!・検索・関連リンクから消え、データは残ります。

## 保存先について

サーバーはありません。データはブラウザの `localStorage` に入ります。

- 作ったものは**その端末のそのブラウザにだけ**残ります
- パソコンで準備した内容を携帯で見せるときは、運営者メニューの
  **データ → 書き出す** で保存したファイルを、携帯で **読み込む**

以前の版で作ったコンテクストは、初めて開いたときに自動で引き継がれます。

## 本番で必要なもの

- サーバーとデータベース、画像の保存先（Firebase などを想定）
- ReMixIt! で生成AIが接続の候補を示し、四軸で採点する流れ（事業計画書の中核）
- 検索ボリューム・広告単価の照会、ハブを主題とするページ
- サインアップ・ログイン・パスワード再設定、読者の参加（コメント等）、友達招待
- 広告のクレジットカード決済、表示割合やタグ指定による価格設定
- 正式な利用規約とプライバシーポリシー

## 画像と文章について

見本の作品画像のうち最初の 8 点は、前田先生の構成図に使われているものです。
50タイトルの 40 点は、ポスター・表紙・キービジュアルを作品紹介のための引用として、
人物や土地の写真を Wikimedia Commons（Public domain／CC0／CC BY／CC BY-SA）から
使っています。撮影者と条件はアプリの「画像の出典」（`#/credits`）にまとめています。
著作権は各権利者に帰属します。一般公開の前には、ポスターや表紙は権利を確かめ、
必要なものは差し替えてください。

見本の本文のうち、HIGHEST 2 LOWEST と グレン・グールド の二件は前田先生の
資料に基づきます。ほかの三件は見本として書いたもので、確かめられる事実だけを
書き、言い伝えは「伝えられる」と書いています。

50タイトルの 44 区間は生成AIの初稿です。先生のテキストが届いたら差し替えます。
